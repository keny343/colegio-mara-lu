## Guidelines

- Capture the demo accounts (`backend/scripts/seed-demo.js`), never a real student
- Do not publish secrets, real minor PII, or `.env` values
- Keep filenames stable — they are linked from the root README
- Viewport 1440×900 for staff screens; full page for the portal, whose value is the
  grade sheet further down
